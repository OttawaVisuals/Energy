▸Conductivity assumptions

Per-bucket thermal conductivity κ (W/m·K), defaulting to VDI 4640 (2010) literature values. Edit a value (clamped to its literature min–max) and every grid cell recomputes exactly as κcell = Σ shareb × κb. Hover the ⓘ for each bucket’s source.

Well marker colours encode open-loop feasibility (not conductivity), so they stay fixed when you edit κ. Each well’s conductivity is recomputed from its lithology bucket when you open its popup.
