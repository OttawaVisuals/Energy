Ottawa Visuals

Canadian energy data, made explorable

Ten interactive tools built from public data — how Canadians heat their homes, what gets built, and what powers the grid. Each one is a Python pipeline turning open data into a self-contained page: no backend, no login, no live queries. Pick one below.

Built by Simon · Ottawa, ON

Energy efficiency professional (Certified Energy Manager, RETScreen Expert) with 10+ years of experience, including energy audits (ASHRAE Level I and II), technical review of energy efficiency measures, and technical analysis of technologies and specific studies (electrification, energy savings potential). This is a personal project to visualize public datasets to inform potential decisions:

  • Data collection/transformation: offline Python scripts to transform and combine datasets into compact, self-contained pages. Python scripts and methodologies clearly explained for transparency.
  • Data analysis: domain-specific cleaning and quality checks (HOT2000/EnerGuide fields, audit noise, paired before/after records). Dropped records are counted, not hidden.
  • Visualization: interactive maps and charts for homeowners and for technical readers, with plain-language and advanced methodology on every page.

If you have feedback or suggestions for new visuals or projects, do not hesitate to contact me.

About the data

Every tool here follows the same pattern: an offline Python pipeline turns a public government (or utility) dataset into compact JSON, and a single self-contained HTML page renders it in your browser — no server, no account, no tracking beyond standard page analytics. Values are modelled or reported figures from the original source, not independently measured; each tool states its own caveats on-page.

Built by Ottawa Visuals, source on GitHub. Website, data pipelines and Python scripts were developed using Claude AI.
